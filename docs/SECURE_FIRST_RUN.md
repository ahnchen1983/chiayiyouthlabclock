# 首次啟用與既有帳號

公開 initialize-database API 已停用，回503且不寫入帳號、模板或憑證。空環境不能登入；不存在的帳號不會被自動建立。既有帳號不重設，原登入與密碼驗證流程保留；登入內部錯誤改回通用訊息，不回傳例外內容。

新環境必須先由有權限的維運人員在獨立、已驗證的環境完成身分與管理員佈建，再驗證登入及角色限制。本修復未提供自助bootstrap、未配置任何持久credential，也沒有操作正式帳號。不要從舊文件還原預設密碼；歷史文件中該密碼已移除，舊初始化描述視為歷史紀錄，不是現行操作指南。

目前沒有安全初始化工具，這是新環境啟用的明確限制；不可為了啟動展示而重新加回固定密碼。合成測試用執行時產生的密碼及mock token，不是可用的正式憑證。

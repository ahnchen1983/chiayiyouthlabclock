# C3a：勞保、就保、健保、勞退自提（2026-10-26）

使用者要求先做計薪政策版本，再接著做勞健保與扣項。C3 拆兩批：本批 C3a 為社會保險；C3b 為所得稅扣繳與兼職二代健保補充保費。

## 做了什麼

- `utils/payroll/insurance.ts` `insuranceForMonth()`：依上表逐項計算，期間在月中變更時勞保／勞退按日數分段，健保看月底所屬期間；勞保投保薪資不在分級表、健保低於第一級、自提超過 6%、期間重疊、費率未建立的月份一律待核，不以 0 計。
- 投保資料時間軸（`insuranceTimeline.ts`）：每人有效期間的勞保投保薪資、是否就保、健保是否在本單位／投保金額／眷屬數、勞退提繳工資／自提率。一位管理者提出、**另一位且非本人**的管理者核定；可登錄未鎖定的過去月份（投保為既成事實），已鎖月份拒絕。核定版本不可改，head 指向現行。
- 計薪：薪資主檔員工改用投保資料計算的保費（`insuranceDetail` 逐項明細）；沒有核定投保資料就待核（「投保資料（勞健保、勞退自提）尚未核定」）。舊路徑員工仍用月覆核手填金額。舊 `systemConfig` 的「應發 × 固定比例」不再用於主檔員工。
- 管理者畫面「投保資料」：查詢員工、目前版本表、提出新版本（勞保級距下拉）、待核定版本核定／退回。

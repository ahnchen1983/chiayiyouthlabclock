# C2b：日別工資候選與合規分流（分批）

基準 C2m d414192；工作分支 fix/pr13-overtime-c2b。C2b1 是無資料庫副作用的 pure module；C2b2 為既有試算附加證據，不替換正式薪資或清除 gate。八月2026正式資料未讀取，所有fixture為合成。

## 法源及適用邊界

2026-10-24查讀全國法規資料庫勞基法（頁面修正日2024-07-31）第24/30/32/32-1/36/39/40及施行細則17。一般8/40制度需明示適用，未實作變形/84-1不可冒充通過；日別、調移、完整正常工資組成、月薪240適用前提都要核定來源。

現行試算網頁查詢日不是八月歷史頁面封存。程式採上述條文級距，不套現行網站最低薪資或全薪進位；holiday日期不由星期/硬編碼日曆產生。事假依1030132065的12h合規分類獨立，不計為actual或自動付全薪。超法定限制保留工時、已知金額與未知分段，不用違法理由歸零。

## C2b1 契約與已做範圍

workdays需核定身份/date/week/daytype/regime，actual、主管核實休息工作、外勤與出差用完整相交分鐘聯集；來源版本與所有重疊refs保留。沒有workday mapping不依零時或間隔魔數重置8h。請假與actual分列，重疊待核。

完整工資組成按有效期間分段：月薪須有240適用確認，時薪不從正兼職推導。平日8h以上4/3、5/3；休息日2h/8h界4/3、5/3、8/3；月薪國假首8h至少額外一日，時薪候選2R實際時間，未滿1h不進位。例假無緊急依據仍保留工資候選並列合規異常；例假超8h或一般超12h本批未知給付段保留null，不0。跨日調薪保留每段basis；月薪假日整日加給跨不同R標待核。

完整七日週界（含跨月）檢核與每日12h分開。超週40h觸發給付分類待覆核，不讓每日未超8h掩蓋。**月46/54及三月138h、連續出勤/輪班間隔、緊急例外完整引擎尚未實作**，不可宣稱完整法遵通過。

補休來源期限/選擇/同意未核會阻擋；即使完整也只保留原工作日各段工資候選，未把帳本時數自動扣成0，未實作支付/到期處理。`knownLiability`是已知分段合計，不能當最終應付；`payableAmount=null`、`formalEligibility=BLOCKED`、final-round-review始終保留。

## 合成人工基準

R200：平日加班119分鐘=4760/9、120=1600/3、121=4850/9；休息480分鐘=7600/3、481=22880/9。月薪48000國假1分鐘額外1600；時薪200國假1分鐘20/3。事假240+工作540→actual540、合規780、平日OT800/3。20–23:30+翌00:30–06同工日540→正常480、OT60，不午夜重置。時薪200→300跨有效期加班各1h，合計2000/3，補休不得改用最新R或抹除義務。

其餘正反例包括週界跨月、48h週、外勤/出差重疊聯集、薪額缺漏/重疊/負值、未知日別/制度/240、契約6h未達8h、未知補休期限與工日衝突。這些是最小候選規則驗證，不是公司制度核定。
